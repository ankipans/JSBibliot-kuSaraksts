Pieslēdz Spotify kontu, lai redzētu dziesmu, kas tiek atskaņota tagad.

Kā pieslēgt Spotify?
  1. Publicē lapu ar https:// adresi (piemēram, GitHub Pages, Netlify, Vercel vai Cloudflare Pages) un atver to no turienes. Spotify nepieņem http:// vai file:// atgriešanās adresi.
  2. Atver Spotify Developer Dashboard, izveido lietotni un nokopē tās Client ID.

  4. Ielīmē Client ID laukā augstāk un nospied Pieslēgties.
